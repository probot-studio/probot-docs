# Kısayollar

Blocks'ta kendi kısayol listesi ya da yardım penceresi yoktur. Bu sayfa iki modda çalışan klavye ve fare
kısayollarını toplar. Mac'te <kbd>Ctrl</kbd> yerine <kbd>Cmd</kbd> kullanılır; istisnalar tabloda yazar.

Bir metin kutusuna yazarken (ör. **Proje**, **Şifre (en az 8)**) kısayollar bloklara uygulanmaz.

<!-- SAY: Kısayollar iki modda büyük ölçüde aynı ama birkaç önemli fark var. -->

## Klavye

| Tuş | Probot Blocks | FTC Blocks |
|---|---|---|
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Seçili bloğu kopyalar. FTC karşılığını da panoya yazar. | Seçili bloğu kopyalar. |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | Seçili bloğu keser. FTC karşılığını da panoya yazar. | Seçili bloğu keser. |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Yapıştırır. | Yapıştırır. Panoda Probot'tan kopyalanmış blok varsa onu farenin olduğu yere yapıştırır. |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Geri alır. | Geri alır. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Yineler. | Yineler. |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Yineler. Mac'te de <kbd>Ctrl</kbd>+<kbd>Y</kbd>'dir. | Çalışmaz. |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Seçili bloğu siler. Yaşam döngüsü blokları silinmez. | Seçili bloğu siler. **to runOpMode** silinmez. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Seçili bloğun sağ tık menüsünü açar. | |
| <kbd>Esc</kbd> | Açık menüyü ya da blok panelini kapatır. | Açık menüyü ya da blok panelini kapatır. |
| <kbd>Esc</kbd> | Örnek penceresini, giriş kartını ve hata formunu kapatır. | Aynı. |

<!-- SAY: Yinele için FTC modunda Ctrl Y değil Ctrl Shift Z kullanılıyor. -->

## Fare

| Hareket | Probot Blocks | FTC Blocks |
|---|---|---|
| Kategoriye bas | Blok paneli açılır. | Blok paneli açılır. |
| Bloğu panelden sürükle | Blok çalışma alanına eklenir, ızgaraya yapışır, yakın bloğa takılır. | Blok eklenir, yakın bloğa takılır. |
| Bloğu çöp kutusuna ya da blok listesine sürükle | Blok silinir. | Blok silinir. |
| Boş alanı sürükle | Çalışma alanı kayar. | Çalışma alanı kayar. |
| Tekerlek | Dikey kaydırır. | **Yakınlaştırır.** |
| <kbd>Shift</kbd>+tekerlek | Yatay kaydırır. | |
| <kbd>Ctrl</kbd>+tekerlek | Yakınlaştırır, uzaklaştırır (0,3-2 kat). | |
| Sağ tık | Bağlam menüsü. | Bağlam menüsü. |
| Blok üstünde bekle | İpucu çıkar. | İpucu çıkar. |
| Panel tutamağını sürükle | Yan panel genişler, daralır. Yalnız fare. | Yan panel genişler, daralır. Fare ve dokunma. |

<!-- SAY: FTC modunda fare tekerleği kaydırmak yerine yakınlaştırıyor. -->

Dokunmatik ekranda blok sürükleme ve kaydırma çalışır, ama araç bilgisayar için tasarlanmıştır.
