# Image list: group C

Common setup: `https://probotstudio.com/builder/`, light theme, 1440×900, `deviceScaleFactor: 2`, clean browser. In the welcome dialog click **Anladım, devam et**, in the cookie notice click **Kabul et**. Snap on, rotation step 45°, mouse layout Onshape. Marker color magenta `#E6007E`. "ready:Omni şasi" = click **Omni şasi** on the "Sahne boş" card and wait until it shows "68 parça".
