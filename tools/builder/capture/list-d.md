# Image list: group D

Common capture settings: `https://probotstudio.com/builder/`, light theme, 1440×900, `deviceScaleFactor: 2`, no cursor, animations finished. Before every capture, click **Anladım, devam et** in the "Tasarım aracı geliştirme aşamasında" dialog and dismiss the cookie notice. Marker color magenta `#E6007E`. Account images are captured in a signed-out browser.
