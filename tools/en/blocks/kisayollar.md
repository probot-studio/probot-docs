# Shortcuts

Blocks has no shortcut list or help window of its own. This page collects the keyboard and mouse
shortcuts that work in both modes. On a Mac, use <kbd>Cmd</kbd> instead of <kbd>Ctrl</kbd>. The table shows the exceptions.

While you type in a text box (for example **Project** or **Password (min. 8)**), shortcuts do not act on blocks.

<!-- SAY: We use mostly the same shortcuts in both modes, but there are a few important differences. -->

## Keyboard

| Key | Probot Blocks | FTC Blocks |
|---|---|---|
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copies the selected block. Also writes its FTC version to the clipboard. | Copies the selected block. |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | Cuts the selected block. Also writes its FTC version to the clipboard. | Cuts the selected block. |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Pastes. | Pastes. If the clipboard has a block copied from Probot mode, pastes it where the mouse pointer is. |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undoes. | Undoes. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redoes. | Redoes. |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Redoes. It is <kbd>Ctrl</kbd>+<kbd>Y</kbd> on a Mac too. | Does not work. |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Deletes the selected block. Lifecycle blocks cannot be deleted. | Deletes the selected block. **to runOpMode** cannot be deleted. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Opens the right-click menu of the selected block. | |
| <kbd>Esc</kbd> | Closes an open menu or the block panel. | Closes an open menu or the block panel. |
| <kbd>Esc</kbd> | Closes the examples window, the intro card and the bug report form. | Same. |

<!-- SAY: In FTC mode we redo with Ctrl Shift Z, not Ctrl Y. -->

## Mouse

| Action | Probot Blocks | FTC Blocks |
|---|---|---|
| Press a category | The block panel opens. | The block panel opens. |
| Drag a block from the block panel | The block is added to the workspace, snaps to the grid and connects to a nearby block. | The block is added and connects to a nearby block. |
| Drag a block to the trash can or the block list | The block is deleted. | The block is deleted. |
| Drag an empty area | The workspace scrolls. | The workspace scrolls. |
| Mouse wheel | Scrolls up and down. | **Zooms in and out.** |
| <kbd>Shift</kbd>+mouse wheel | Scrolls sideways. | |
| <kbd>Ctrl</kbd>+mouse wheel | Zooms in and out (0.3x to 2x). | |
| Right-click | Context menu. | Context menu. |
| Hover over a block | A tooltip appears. | A tooltip appears. |
| Drag the panel handle | The side panel gets wider or narrower. Mouse only. | The side panel gets wider or narrower. Mouse and touch. |

<!-- SAY: In FTC mode we zoom with the mouse wheel instead of scrolling. -->

On a touchscreen, dragging blocks and scrolling work, but the tool is made for a computer.
